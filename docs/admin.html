Flight schedule

Flights

Reporting time = scheduled departure (GMT) + 1:25 for A320/A321, or + 1:10 for B777/A330, shown in Kuwait time. Flights with a missing or unknown aircraft type are not assigned a room until you choose the type. The public schedule source can miss same-day retimes: if a departure is wrong, type the correct GMT time and select Set — later updates keep your time.

Upload reporting list (Excel)

One row per flight: flight, reporting time (Kuwait time, used exactly as written), optional date and destination, and one or more name columns. Name columns can be called Chief Cabin / SCCM, CCI, or FSS / Supervisor — every name is shown on the screen with its title. Several names in one cell can be separated with “/”, and a title can be written next to a name, e.g. Sara (FSS).
