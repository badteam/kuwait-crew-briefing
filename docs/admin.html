Flight management

Briefing time = file time + 85 minutes for small aircraft, or +70 minutes for the 777 and A330. Each session lasts 10 minutes.

Columns and import templates

Flights: flight, destination, aircraft, date, time, sccm. Use YYYY-MM-DD dates and HH:MM times in Kuwait time. Aircraft: SMALL, A320, A321, B777 or A330.

Crew: flight, sccm. Add date when a flight number occurs on multiple days. Only the first worksheet is read; convert formulas to values before uploading.
